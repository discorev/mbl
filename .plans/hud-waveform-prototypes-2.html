How it would be built

drawingA CALayer subclass drawing N sine strands per frame with CGContext strokes, .plusLighter blend and a shadow for glow. No Metal needed at this size.
signalAmplitude from the same 100 ms RMS the speech gate uses, smoothed with fast attack and slow release. Strand frequencies are fixed; only amplitude and phase speed respond to level.
statesListening: audio-driven wave. Transcribing: strands relax to a flat line in ~200 ms, then a bright pulse sweeps along it every 0.7 s. Cleaning: the line pinches into a five-colour orbit. Done: orbit unwinds to a still line and fades with the HUD. Each state has its own shape so the strip never looks like it might still be listening.
paletteAmber #FFB347, coral #FF5E8A, magenta #C64BFF, violet #6B5BFF, cyan #3FD6FF. Lives in one place so it can be tuned.
