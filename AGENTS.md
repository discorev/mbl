# Working in this repo

## Plans versus design concepts

`.plans/` holds two different things.

- **Implementation plans** (e.g. `signed-releases-and-updates.html`) record
  decisions and sequencing for a feature. Commit them.
- **Design concept pages** (icon ideas, HUD prototypes, visual explorations)
  are decision-making tools. They are uploaded to planreview for review and
  are never committed. Do not `git add` them.

The two HUD prototype pages already tracked predate this rule.

## Commits

- Commit only when asked, using the commit-changes skill.
- Never commit `build/` or generated bundles.
